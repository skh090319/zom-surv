# Zombie Survival 파일 구조

- `01-core.js`: 캔버스, 이미지 로딩, 플레이어와 전역 상태
- `02-upgrades.js`: 증강 목록, 레벨업, 증강 선택
- `03-input.js`: 키보드·마우스 입력
- `04-weapons-spawn.js`: 총기, 발사, 좀비·아이템 생성과 처치
- `05-skills.js`: 비전, 양자, 드론, 중력장 등 전투 스킬
- `06-entities-update.js`: 플레이어·좀비·아이템 업데이트와 충돌
- `07-world-render.js`: 배경과 게임 오브젝트 렌더링
- `08-ui.js`: HUD, 홈, 캐릭터 선택, 일시정지, 레벨업 화면
- `09-main.js`: 초기화, draw, 메인 게임 루프

파일 이름의 번호는 로딩 순서입니다. `index.html`의 script 순서를 바꾸지 마세요.
