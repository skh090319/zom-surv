# Zombie Survival 파일 구조

- `01-core.js`: 캔버스, 이미지 로딩, 플레이어와 전역 상태
- `02-upgrades.js`: 증강 목록, 레벨업, 증강 선택
- `03-input.js`: 키보드·마우스 입력
- `04-weapons-spawn.js`: 총기, 발사, 좀비·아이템 생성과 처치
- `05-skills.js`: 비전, 양자, 드론, 중력장 등 전투 스킬
- `06-entities-update.js`: 플레이어·좀비·아이템 업데이트와 충돌
- `07-world-render.js`: 배경과 게임 오브젝트 렌더링
- `08-ui.js`: HUD, 홈, 캐릭터 선택, 일시정지, 레벨업 화면
- `09-main.js`: 초기화, draw, 메인 게임 루프

파일 이름의 번호는 로딩 순서입니다. `index.html`의 script 순서를 바꾸지 마세요.


## 썬콜 해금
- 일반 처치와 폭탄 처치를 모두 포함한 누적 좀비 200마리 처치 시 해금됩니다.

## 아스트라 스킬 / 이펙트 검증

- Q: 모든 공전성을 발사하고 관통·귀환합니다. 재사용하면 즉시 회수합니다.
- E: 일반 적을 당기는 중력정이 응축 후 폭발합니다. 보스와 보스 분신은 이동 방해 면역입니다.
- R: 10레벨부터 일반 적을 6초간 포획·공전시키고, 종료 시 현재 조준 방향으로 발사합니다. 포획할 적이 없으면 가상 천체를 생성합니다. 보스 최대 체력 추가 피해는 궁극기 전체에서 기본 4.5%를 나누어 적용합니다.
- 전투 로직은 `js/04-astra.js`, 지연 생성·재사용하는 성운 텍스처와 계층별 이펙트는 `js/04-astra-vfx.js`에 있습니다.
- `node --test tests/*.test.cjs`로 회귀 테스트를 실행합니다.
- 로컬 HTTP 서버에서 `/tests/astra-preview.html`을 열면 Q/E/R 단계별 화면, 휴대폰 레이아웃, 250마리 포획 성능, 실제 게임 업데이트·이동을 재현할 수 있습니다. 이 검수 화면은 PWA를 등록하지 않고 누적 처치 수를 저장하지 않습니다.
